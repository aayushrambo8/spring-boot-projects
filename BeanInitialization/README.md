# BeanInitialization

This is a Spring context project demonstrating bean initialization and configuration.

## Project Configuration

- **Java Version**: 17
- **Framework**: Spring Context (7.0.7)
- **Build Tool**: Maven

## Getting Started

### Prerequisites
- JDK 17
- Maven

### Run the Project
To build and run the application, use the following Maven commands:

```bash
mvn clean compile
mvn exec:java "-Dexec.mainClass=live.aayush.Main"
```
